## Quick start

This template renders as-is with placeholder data, so you can confirm your
setup works before touching any content:

```r
install.packages("renv")   # if not already installed
quarto::quarto_render("analysis.qmd")
quarto::quarto_render("index.qmd")
```

Or in Positron/RStudio: open each file and click **Render**.

## What to fill in

Every file with a `FILL IN` marker needs your input. In order:

1. **`data/raw/`** — replace `example_data.csv` with your real raw data.
   Never edit files in this folder by hand once real data lands here.
2. **`analysis.qmd`** — replace the cleaning steps, model, and figure with
   your own. Keep writing derived data to `data/derived/` and outputs to
   `outputs/`.
3. **`references/references.bib`** — replace the example entry with your
   real citations.
4. **`index.qmd`** — write your manuscript. Reference figures/tables
   produced by `analysis.qmd`.
5. **`_quarto.yml`** — uncomment `csl:` once you've picked a target
   journal's citation style, and `docx:` if they want a Word submission.
6. **This README** — replace this whole file with a description of your
   actual project once things are real (see the "Final README" template
   in the guide, chapter 1).

## Day 1 checklist (see guide chapter 1 for details)

- [ ] Replace placeholder data in `data/raw/`
- [ ] `renv::init()` then `renv::snapshot()`, commit `renv.lock`
- [ ] Git init, push to GitHub (public)
- [ ] Connect the GitHub repo to Zenodo (Settings → GitHub → toggle on)
- [ ] Reserve a Zenodo DOI once ready to submit (guide chapter 4)

## Folder structure

```
.
├── _quarto.yml
├── index.qmd              # manuscript (text only)
├── analysis.qmd            # all R code
├── data/
│   ├── raw/                # original data — never modify
│   └── derived/             # cleaned data produced by analysis.qmd
├── outputs/
│   ├── figures/            # figures generated by analysis.qmd
│   └── tables/             # tables generated by analysis.qmd
├── references/
│   └── references.bib
└── README.md
```
